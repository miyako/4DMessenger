This sample database demonstrates a simplified peer-to-peer messaging application built with 4D's modern TCPListener and TCPConnection classes. The application enables inter-user communication with support for text, images, and file transfers up to 64MB, featuring encrypted exchanges and channel-based message filtering. 

To get started:

- Open the project with 4D version 20 R10 or 4D v21 beta
- Execute the project method "app_messenger_main" to launch the main application form
- In the Node section, enter the IP address and the username
- In the Channel section, enter the channel and recipients names
- Messages can be sent after selecting the referenced channel
